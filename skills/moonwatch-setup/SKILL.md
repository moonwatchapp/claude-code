# Setup Wizard

Read `../moonwatch/references/moonwatch-guide.md`, then follow the `## Setup Wizard` section.

Use `npx -y @moonwatch/cli@latest` for every Moonwatch CLI command. Do not check for, install, or use a global CLI binary.
